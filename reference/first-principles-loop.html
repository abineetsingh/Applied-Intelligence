Quick reference · seven moves

The first-principles loop

Reduce the problem to decision-relevant primitives, then rebuild only what the evidence supports.

  1. Specify: What decision, prediction, or explanation is required? What is the deadline?
  2. Atomize: List primitives, hard constraints, controllable variables, and unknowns.
  3. Separate: Label observations, assumptions, inferences, forecasts, and preferences.
  4. Model: Build at least two mechanisms that could explain the evidence.
  5. Quantify: Estimate base rates, magnitudes, probabilities, ranges, and sensitivities.
  6. Target: Find the uncertainty most likely to change the action; seek the cheapest useful evidence.
  7. Act: Choose with a downside limit, confidence, falsifier, and review condition.

Pattern-recognition test

Before importing a solution from another domain, name the shared mechanism. If you can name only similar vocabulary, appearance, or outcome, you have a surface analogy—not a structural pattern.

Speed rule

First become accurate without a clock. Then compress the representation. Only then reduce the time limit. If quality falls, return to the last reliable speed.

When information is scarce

Use base rates for the initial model, express a range rather than a point, protect against ruin, and ask only for information that could change the action.
