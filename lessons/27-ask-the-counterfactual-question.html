Ask the counterfactual question

Define causation as the difference an action makes compared with a credible alternative.

Mission connection

Strategic action changes systems. Causal reasoning predicts what an intervention will do, not merely what variables accompany one another.

Retrieve before reading

Why was the AI engagement result in Lesson 26 exploratory rather than confirmatory?

Reveal after answering

The team selected one winner among many metrics and stopped flexibly, so a new fixed test was needed to separate effect from selection noise.

The mental model

A causal effect compares potential outcomes under different actions for the same unit. Because only one can be observed, causal reasoning constructs a credible comparison using randomization, design, assumptions, or natural variation.

  1. Name the intervention precisely.
  2. Name the outcome and measurement horizon.
  3. Write the alternative action or no-action condition.
  4. Define the target population.
  5. Ask what makes the comparison group credible.

Worked case: customers using a feature retain more

Feature users may retain because the feature helps, or motivated users may both discover the feature and remain. The causal question is whether enabling or encouraging comparable users to use it changes retention relative to not doing so.

Deliberate practice

Rewrite three causal claims from work or news as treatment, comparison, outcome, population, and horizon. Identify the unobserved counterfactual in each.
