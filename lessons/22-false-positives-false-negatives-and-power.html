False positives, false negatives, and power

Design evidence around the cost of each mistake and the chance of detecting what matters.

Mission connection

Exceptional judgment distinguishes a noisy estimate from evidence strong enough to change a costly action.

Retrieve before reading

Why is statistical detection insufficient for a product decision?

Reveal after answering

A decision needs effect magnitude, uncertainty, implementation costs, reversibility, and practical thresholds—not only whether a null was rejected.

The mental model

A false positive acts on an effect that is not real; a false negative misses one that is. Power is the probability a design detects a specified real effect. Error rates become decisions only after attaching consequences.

  1. Write the action caused by a positive result.
  2. Price the consequence of a false positive.
  3. Price the consequence of a false negative.
  4. Choose the minimum effect worth detecting.
  5. Check whether sample size and noise provide adequate power.

Worked case: fraud blocking versus feature testing

A false fraud flag harms a legitimate customer immediately; a missed fraud creates financial loss. In a reversible UI test, a temporary false positive may be cheap. The same statistical threshold should not govern both decisions.

Deliberate practice

Build a two-by-two error table for one live decision. Put a concrete action and cost in every cell, then state which error deserves more protection.

Deliverable: An error-cost matrix and minimum detectable effect.
