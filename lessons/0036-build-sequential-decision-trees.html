Build sequential decision trees

Model choices, uncertain events, and future options in the order they occur.

Mission connection

Insight becomes judgment only when it changes action while respecting values, downside, reversibility, and the cost of delay.

Retrieve before reading

What is the difference between an objective and an alternative?

Reveal after answering

An objective states what matters; an alternative is an action available for pursuing those objectives.

The mental model

Decision trees separate choices from chance events and show how information changes later options. Solve backward: evaluate terminal outcomes, average chance branches, then select the best action at each decision node.

  1. Draw the first decision node.
  2. Add chance events that follow each action.
  3. Add later choices available after observing events.
  4. Assign probabilities and utilities at endpoints.
  5. Fold the tree backward and test sensitivity.

Worked case: build versus prototype versus interview

A founder can build now, run a concierge prototype, or conduct interviews. The prototype costs time but reveals demand before the full build, preserving a later choice. Its value comes partly from information and partly from delaying irreversible commitment.

Deliberate practice

Draw a two-stage tree for a live decision with at least one information-gathering action and one later choice. Solve it backward using rough values.

Deliverable: A decision tree and the branch where information changes action.

Transfer it

A staged position entry is a sequential decision only if later sizing depends on new evidence rather than price-anchored emotion.
